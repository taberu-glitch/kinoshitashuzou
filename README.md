# きのした酒造オンラインショップ

白基調の日本酒ECサイトのデモです。HTML 1ファイル（`index.html`）で動作し、ビルドは不要です。

## できること
- 年齢確認
- 商品一覧・カテゴリ絞り込み・商品名検索・商品詳細
- カート（ブラウザの localStorage に保存）
- お届け先・お支払い方法の入力（入力チェック、地域別送料、クール便、代引手数料、熨斗・包装）
- ご注文内容の確認 → 決済代行サービスへの引き渡し画面（デモ）

## GitHub Pages で公開する
1. このフォルダの中身をリポジトリのルートに置いて push します。
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示されます。

## 本番化の前に差し替えるもの
- 特定商取引法に基づく表記・酒類販売管理者・通信販売酒類小売業免許（「記入」欄）
- 電話番号（サンプル）
- 商品画像（現在はSVGで描いた仮の瓶）
- 決済の引き渡し画面を Stripe・PAY.JP などの実際の決済につなぐ処理

※ 「きのした酒造」はデモ用の名称で、商品・会社情報は架空のものです。
